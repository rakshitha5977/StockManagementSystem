# Stock Management System

A web-based Stock Management System developed using PHP and MySQL
to manage products, categories, suppliers, stock, and billing.

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Features
- Product Management
- Category Management
- Stock Management
- Billing
- Search
- Database Management

## How to Run
1. Install XAMPP
2. Clone the repository
3. Place the project inside htdocs
4. Start Apache and MySQL
5. Import the SQL database
6. Open the project in the browser
